Política de privacidad

Última actualización: 27 de octubre de 2026

Esta política describe cómo la aplicación Núcleo Carmesí Content System (“la aplicación”) usa los datos a los que accede a través de los Servicios de API de YouTube. La aplicación es una herramienta interna que usa únicamente el dueño del canal de YouTube Núcleo Carmesí para publicar videos en ese mismo canal. No se ofrece al público ni la usan terceros.

Servicios de API de YouTube

La aplicación usa los Servicios de API de YouTube. Al usarla, aceptas los Términos del Servicio de YouTube. El tratamiento de datos por parte de Google se rige por la Política de Privacidad de Google.

Qué datos se usan

  • Permiso de subida de videos (youtube.upload): la aplicación lo usa solo para subir videos, con su título, descripción, etiquetas y miniatura, al canal de Núcleo Carmesí.
  • Token de autorización de Google: se guarda únicamente en el equipo del dueño del canal, para no tener que autorizar en cada publicación.

La aplicación no lee, recopila ni almacena datos de otros usuarios, suscriptores o espectadores, ni información personal como nombre, correo, contactos o historial de visualización.

Uso y divulgación

Los datos se usan exclusivamente para publicar el contenido del canal. No se venden, no se comparten con terceros, no se usan con fines publicitarios y no se transfieren a otros servicios.

Almacenamiento y eliminación

El token de autorización permanece en el equipo del dueño del canal hasta que se revoca el acceso o se elimina el archivo. Los videos publicados se rigen por los términos de YouTube.

Cómo revocar el acceso

Puedes revocar en cualquier momento el acceso de la aplicación a tu cuenta desde la página de permisos de seguridad de Google: https://security.google.com/settings/security/permissions.

Cambios

Si esta política cambia, se actualizará esta página y la fecha de última actualización.

Privacy Policy

Last updated: October 27, 2026

This policy describes how Núcleo Carmesí Content System (“the application”) uses data accessed through the YouTube API Services. The application is an internal tool used solely by the owner of the Núcleo Carmesí YouTube channel to publish videos to that same channel. It is not offered to the public and is not used by third parties.

YouTube API Services

The application uses the YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is governed by the Google Privacy Policy.

Data used

  • Video upload permission (youtube.upload): used only to upload videos, with their title, description, tags and thumbnail, to the Núcleo Carmesí channel.
  • Google authorization token: stored only on the channel owner's computer so that authorization is not required for every upload.

The application does not read, collect or store data about other users, subscribers or viewers, nor personal information such as name, email, contacts or watch history.

Use and disclosure

Data is used exclusively to publish the channel's content. It is not sold, not shared with third parties, not used for advertising and not transferred to other services.

Storage and deletion

The authorization token remains on the channel owner's computer until access is revoked or the file is deleted. Published videos are governed by YouTube's terms.

Revoking access

You can revoke the application's access to your account at any time via the Google security settings page: https://security.google.com/settings/security/permissions.
